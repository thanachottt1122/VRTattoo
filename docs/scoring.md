# ลายสักและคะแนน

- **ลายสักและคะแนน:**
  - ลูกค้านอนลงแล้วสุ่มลายจากคลัง (วันแรกได้ easy บ่อย วันหลัง ๆ เจอ hard บ่อยขึ้นตาม `ShopDayManager.DifficultyRamp` ไม่ซ้ำกับคนก่อน — [shop-day.md](shop-day.md)) แสดงเป็นลายเส้นสีม่วงจางบนแขนท่อนล่าง (กรอบลาย 14 ซม. ตั้งตามแนวแขน หัวลายชี้ไปทางข้อศอก ด้านกว้างพันรอบแขน) แยกจากหมึกจริง ชื่อลายและระดับขึ้นบนการ์ดงาน ([ui.md](ui.md))
  - กดปุ่ม DONE บนการ์ดงาน (ชี้+trigger / grip / จิ้ม) หรือ J (เฉพาะ Editor) เพื่อส่งงาน: การ์ดแสดงคะแนน 0–100 นับขึ้น ดาว 1–3 และแต้มที่ได้ 3.5 วิ แล้วลูกค้าเดินออก
  - คุณภาพ = 100 × Accuracy × max(0, 1 − messRatio / `messLimit`)^`messPower`
    - Accuracy = สัดส่วนเส้นลายที่มีหมึกอยู่บนหรือห่างไม่เกิน `coverTolerance` 1.5 มม.
    - messRatio = พื้นที่หมึกนอกเส้นลาย (ทั้ง canvas ละเลงนอกกรอบลายก็นับ) ÷ พื้นที่ลาย **ถ่วงตามระยะ**: แต่ละพิกเซลหนัก clamp01((ระยะถึงเส้นลาย − tolerance) / `messFalloff` 3.2 มม.) โดย tolerance = `messTolerance` 0 + `needleSlack` 1.1 × รัศมีหัวเข็มที่ลงหมึกพิกเซลนั้น (อ่านจาก needle map ของ `TattooCanvas`) → ขอบล้นตามธรรมชาติของหัวใหญ่ไม่โดนหัก เส้นส่ายนิดหน่อยโดนหักนิดเดียว หมึกที่ไกลเส้นโดนเต็ม
    - คุณภาพ = 100 × Accuracy × (1 − min(1, messRatio / `messLimit` 1)^`messPower` 0.58) (power < 1 = เลอะนิดเดียวก็เห็นผล แต่ไม่ดิ่งเป็น 0 เร็ว) ทุกค่าปรับที่ `TattooJobManager.scoring` (ค่าเริ่มต้น `TattooScoringRules.Default`)
    - ระยะถึงเส้นใช้ chamfer distance (`TattooScorer.DistanceToMask`) ส่งงานหนึ่งครั้ง ~200 ms (อ่าน RenderTexture 2 อัน)
    - ผู้เล่นไม่เห็นสูตร; Console พิมพ์ `accuracy / mess area / quality / +points` ทุกครั้งที่ส่ง (Mess = round(100 × Accuracy) − คุณภาพ)
  - ผลจำลอง (เมนู `VRTattoo/Simulate Tattoo Scores` ใช้ค่าจาก scene, ต่ำสุด/เฉลี่ย/สูงสุด ทุกลาย × หัวเข็ม 3 ขนาด) ใช้เวลา ~30 วิ:

## เวลา
- `TattooJobManager.patience` (`PatienceScoring`): เวลาต่อลาย easy 60 / medium 90 / hard 130 วิ เริ่มตอนลูกค้านอนลง (นับตาม `CustomerPatience`)
- **ช้า:** เลยเวลา → หักคุณภาพ `overtimePenaltyPerSecond` 1 ต่อวินาที สูงสุด `maxOvertimePenalty` 30 **ก่อน** คิดอารมณ์/ดาว/แต้ม
- **เร็ว:** ใช้เวลา ≤ `fastFraction` 50% → โบนัสแต้ม `fastBonus` 25% × (1 − ใช้ไป/50%) (เช่นใช้ 20% ได้ +15%) เฉพาะคุณภาพ ≥ `bonusMinQuality` 40 การ์ดขึ้น "FAST +x%"
- ความเจ็บถึง 100% → ลูกค้าเดินออก ได้ 0 ([customer-reactions.md](customer-reactions.md))
- Log: `quality 95, time 140/130s (-10, bonus +0 %) -> 85, +170` ผลทดสอบ: ส่งที่ 5/130 วิ → +23% (95 × 2 × 1.23 = 234), 18/90 วิ → +15%, เกิน 10 วิ → 95 เหลือ 85 (Happy)
