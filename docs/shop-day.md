# เงิน ทิป และวันทำงาน

## เงิน (`TattooJobManager.money` = `MoneyRules`)
- ค่าสัก = ราคาลาย × คุณภาพ/100 × (1 + โบนัสเร็ว) ปัดเป็นดอลลาร์เต็ม
  - ราคาลาย: easy **$50** / medium **$80** / hard **$120**
  - คุณภาพที่ใช้คิดเป็นค่าหลังหักเวลาเกินแล้ว ส่วนโบนัสเร็วใช้ค่าเดียวกับแต้ม ([scoring.md](scoring.md#เวลา))
- **ทิป:** ให้เฉพาะ 3 ดาว (คุณภาพ ≥ 90 ตาม `JobCard.starThresholds`) สุ่ม `tipFraction` 10–30% ของราคาลาย (อย่างน้อย $1)
- ถ้าลูกค้าเดินออกเพราะเจ็บ ได้ $0
- แต้ม (points) ยังคิดเหมือนเดิม แต่แสดงแค่ใน log
- ตัวอย่าง log: `crown skull: ... quality 95, time 17/60s (-0, bonus +11 %) -> 95, +106 pts, 3 stars, $53 + tip $10 (bank $63), mood Ecstatic`
- เงินรวม (bank) อยู่ที่ `ShopDayManager.Money` ถ้าไม่มี `shopDay` จะเก็บแค่ในเซสชันนั้น

## วันทำงาน (`ShopDay` → `ShopDayManager`)
- 1 วัน = `customersPerDay` 5 คน นับทุกคนที่เดินเข้าร้าน ไม่ว่าจะสักเสร็จ เดินออกเพราะเจ็บ หรือรอนานจนเดินออก
  - `CustomerQueueManager.BeginDay(count, patienceScale)` ให้ลูกค้าเข้าร้านได้แค่ `count` คน
  - `DayDone` จะเป็นจริงเมื่อลูกค้าเข้าครบแล้ว ไม่มีใครอยู่บนเตียงหรือโซฟา และคนสุดท้ายเดินถึงประตูแล้ว
- ลำดับในวัน:
  1. ป้าย "Day N" (`DayBanner`) ขึ้น ระหว่างนี้ยังไม่มีลูกค้า
  2. ลูกค้าทยอยเข้าร้านจนครบ 5 คน
  3. คนสุดท้ายถึงประตู → รอ `summaryDelay` 1 วิ → ซ่อนการ์ดงาน แล้วแสดงแผ่นสรุป ([ui.md](ui.md#สรุปวัน-shopdaydaysummary-daysummarypanel))
- **ยากขึ้นทุกวัน:**
  - ลาย: `DifficultyRamp` = (วัน − 1) / `rampDays` 5 ใช้แทนตัว ramp เดิมของ `TattooJobManager` (startWeights 0.7/0.25/0.05 → endWeights 0.2/0.4/0.4) ค่าจะเต็มที่ในวันที่ 6
  - ความอดทน: × `patiencePerDay` 0.92 ต่อวัน ต่ำสุด `minPatience` 0.6 ใช้ทั้งเวลารอบนโซฟาและเวลาบนเตียง (`CustomerPatience.scale` ตั้งตอน spawn)
  - ตัวอย่างวันที่ 2: เวลาบนเตียงลาย medium 90 → 82.8 วิ, เวลารอบนโซฟา 138–202 วิ
- สถิติวัน (`DayStats`):
  - ค่าสัก, ทิป
  - คะแนนเฉลี่ย: คิดจากลูกค้าที่ขึ้นเตียง คนที่เดินออกเพราะเจ็บนับเป็น 0
  - พอใจ: อิโมจิตาหัวใจหรือยิ้ม
  - โกรธ: อิโมจิโกรธ, เดินออกเพราะเจ็บ, หรือรอบนโซฟาจนเดินออก (`onCustomerGaveUp`)
  - ดาวรวม

## บันทึก (`ShopSave`)
- ไฟล์ JSON `Application.persistentDataPath/vrtattoo_save.json` เก็บ `{ "day": 2, "money": 141 }`
  - บน Editor ของเครื่องนี้อยู่ที่ `%USERPROFILE%/AppData/LocalLow/DefaultCompany/VRTattoo_2/`
- เขียนไฟล์ตอนจบวัน โดยเก็บเป็นวันถัดไปพร้อมเงินรวม และเขียนอีกครั้งตอนกด Restart (วัน 1, $0)
- ถ้าออกเกมกลางวัน เปิดใหม่จะเริ่มวันนั้นใหม่ด้วยเงิน ณ ตอนเริ่มวัน
- ล้างเซฟเอง: ลบไฟล์นี้ได้เลย
- **NEXT DAY** = ไปวันถัดไป, **RESTART** = กลับไปวัน 1 เงิน $0

## ผลทดสอบ (log, timeScale 4, `SubmitForTest`)
- วันที่ 1 ส่งงานคุณภาพ 95 / 75 / 50 / ให้เดินออกเพราะเจ็บ / 20 → ค่าสัก $131 ทิป $10 คะแนนเฉลี่ย 48 พอใจ 2 โกรธ 2 ดาว 7 เงินรวม $141 ไฟล์เซฟเป็น `day 2, money 141`
- กด NEXT DAY ด้วย ray (ทางเดียวกับคลิกเมาส์ใน Desktop mode) → วันที่ 2 ramp 0.2 ความอดทน ×0.92 → จบวันที่เงินรวม $348
- ออกจาก Play แล้วเข้าใหม่ → โหลดได้วันที่ 3, $348 (ramp 0.4, ความอดทน ×0.85) กด Restart → กลับเป็นวันที่ 1, $0
